# NumPy Learning & Practice

This repository contains my **NumPy learning journey**, including concepts, examples, practice exercises, and hands-on problems that I worked through while learning NumPy for **Python and Data Analytics**.

The repository is mainly focused on building a strong understanding of NumPy arrays and learning how to efficiently work with numerical data.

## 📚 Topics Covered

### 1. Array Basics

* Creating NumPy arrays
* 1D and 2D arrays
* `np.array()`
* `np.arange()`
* `np.zeros()`
* `np.ones()`
* `np.linspace()`
* Random array generation
* Array attributes

  * `shape`
  * `size`
  * `dtype`
* Basic array methods

  * `min()`
  * `max()`
  * `sum()`
  * `mean()`
  * `std()`
  * `argmax()`

### 2. Array Indexing & Slicing

* Accessing elements
* Vector indexing
* Vector slicing
* Matrix indexing
* Matrix slicing
* Row and column selection
* Boolean indexing
* Conditional filtering

Examples include selecting specific rows/columns, extracting portions of arrays, and filtering values based on conditions.

### 3. Array Operations

* Addition
* Subtraction
* Multiplication
* Division
* Floor division
* Power operations
* Broadcasting
* Deep and shallow copy concepts

### 4. Matrix Operations

* Matrix creation
* Element-wise multiplication
* Matrix multiplication
* `np.dot()`
* `@` operator
* Transpose using `.T`

### 5. Array Manipulation

* Reshaping arrays
* Vertical stacking with `np.vstack()`
* Horizontal stacking with `np.hstack()`
* Column stacking with `np.column_stack()`
* Splitting arrays with `np.hsplit()` and `np.vsplit()`

### 6. Practice Exercises

The repository also contains hands-on exercises designed to apply NumPy concepts to practical problems.

Some examples include:

* **Valid Sudoku**

  * Checking row and column sums using NumPy
* **Student Data Analysis**

  * Calculating average age
  * Extracting subject marks
  * Finding maximum marks
  * Filtering students based on marks
  * Updating values
  * Calculating column-wise averages
  * Applying conditional changes
